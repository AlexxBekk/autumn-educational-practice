Стадия самодостаточна, общий код приложения из практики 21.09.2026 скопирован в папку Приложение, старые папки не трогал.

Окон четыре: реестр партнеров (/), карточка партнера (/partner), история реализации (/history) и калькулятор материалов (/calculator). Кнопка "История продаж" есть в каждой карточке реестра, кнопка калькулятора в шапке.

Нужны Node.js 24.2+ и PostgreSQL с базой после практики 21.09.2026. Скопируйте .env.example в .env и укажите пароль от базы, затем:

```
npm install
psql -U postgres -d partners_db -f "Разработка ядра алгоритма расчета материалов/reference-tables.sql"
npm test
npm start
```

Приложение откроется на локал хосте http://localhost:3000.

Ошибки пишутся в app.log рядом с package.json, в репозиторий этот файл не идет.
