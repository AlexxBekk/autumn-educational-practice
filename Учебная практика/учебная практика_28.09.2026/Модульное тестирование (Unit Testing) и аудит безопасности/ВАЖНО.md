ВАЖНО

Тесты на встроенном node:test, сторонних библиотек не ставил. Запуск npm test из папки практики.

Тесты ходят в реальную базу, потому что метод по условию сам читает справочники. Данные не меняют, только читают.

logger.js пишет дату, время и текст ошибки в app.log рядом с package.json. Сам app.log в репозиторий не идет, он появляется при первой ошибке.

Общий код всех окон лежит в соседней папке Приложение. Логирование подключено к серверу там же, в server.js, и аудит ссылается на файлы оттуда, в них лежат запросы к партнерам.
