Все четыре задания это один проект: package.json лежит в этой папке, задания подключают код друг друга. Таблица продаж, которая в задании называется sales_history, в нашей схеме из практики 07.09.2026 называется deliveries.

Нужны Node.js 24.2+ и PostgreSQL с базой из прошлой практики. Скопируйте .env.example в .env и укажите пароль от базы, затем:

```
npm install
npm test
npm run test:coverage
npm start
```

Приложение откроется на локал хосте http://localhost:3000.
