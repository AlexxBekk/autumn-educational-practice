Стадия самодостаточна: нужные файлы из практики 19.09.2026 скопированы сюда, старые папки не менялись.

Приложение состоит из двух окон. Главное окно (/) это реестр партнеров с кнопкой «Добавить партнера», карточка партнера (/partner) это форма добавления и редактирования. Заголовок карточки меняется в зависимости от режима.

Перед первым запуском нужно один раз выполнить миграцию: она добавляет в таблицу partners тип, адрес и ФИО директора, переводит рейтинг в целое число и выносит тип из названия («ООО "Логистик-Экспресс"» становится типом ООО и названием Логистик-Экспресс).

Нужны Node.js 24.2+ и PostgreSQL с базой из практики 07.09.2026. Скопируйте .env.example в .env и укажите пароль от базы, затем:

```
npm install
psql -U postgres -d partners_db -f "Интеграция формы с БД (CRUD-операции и обновление UI)/migration.sql"
npm start
```

Приложение откроется на локал хосте http://localhost:3000.

Ссылочная целостность поддерживается в коде: partner_id при сохранении не меняется, поэтому отгрузки партнера остаются привязанными к той же карточке; редактирование несуществующего партнера возвращает 404, а повторный ИНН или email возвращает 409 вместо создания дубля.
